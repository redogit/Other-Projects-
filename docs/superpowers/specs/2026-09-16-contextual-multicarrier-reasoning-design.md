# Contextual Multi-Carrier Reasoning Design — 2026-09-16

## Status

Approved architectural successor to:

1. `GSFL COMPLETE_BOUNDED_V0_1`;
2. `GSFL_V0_1_OPERATOR_PROJECTION`;
3. `GSFL_V0_1_BIDIRECTIONAL_MACRO_CYCLE`.

This successor does not rewrite any predecessor.

## Goal

Represent one semantic object through four parallel reasoning carriers—**symbolic, analytical, computational, and analogical**—while resolving word/phrase roles from context, surface, interpreter, time, relations, and obligation. Compare invariants and representation-specific deltas, reconstruct analogical transports using a BBF-style fold/transform/unfold check, and gate promotion so agreement or coherence cannot silently become truth or independent evidence.

## Core distinction

```text
WORD != FIXED_ROLE
ROLE_BINDING != PERMANENT_DEFINITION
MULTI_ROLE != AMBIGUITY_FAILURE
CARRIER_AGREEMENT != INDEPENDENT_VERIFICATION
ANALOGY != EVIDENCE_TRANSFER
COMPUTATIONAL_WITNESS != GENERAL_PROOF
ANALYTICAL_COHERENCE != EMPIRICAL_VALIDATION
SYMBOLIC_COMPRESSION != TRUTH
```

A word occurrence is interpreted as a contextual event rather than a permanent type:

```text
role_occurrence = F(word, surface, context, interpreter, time, relations, obligation)
```

The bounded implementation does **not** claim to solve natural-language semantics. It stores explicit contextual role candidates supplied or generated by declared deterministic rules and preserves interpreter-specific disagreement.

## Architecture

### 1. Contextual role resolution

A `RoleContext` contains:

- `surface`;
- `context`;
- `interpreter`;
- `time_label`;
- `obligation`;
- `relations`;
- optional explicit `role_hints`.

A `RoleBinding` contains:

- occurrence text;
- interpreter;
- candidate roles with bounded support scores;
- selected active roles;
- unresolved roles;
- provenance.

Multiple roles may be active simultaneously. Resolution is interpreter-local and time-local.

### 2. Four reasoning carriers

Every admitted semantic object may be projected into:

- `SYMBOLIC` — compact symbols, equations, labels, formal relations;
- `ANALYTICAL` — decomposed assumptions, consequences, distinctions, arguments;
- `COMPUTATIONAL` — executable finite witnesses, deterministic checks, explicit outputs;
- `ANALOGICAL` — mapped source/target structures for discovery and comparison.

Each carrier produces a `CarrierRecord` containing representation, declared invariants, introduced claims, omitted claims, provenance, and evidence ceiling.

### 3. Cross-carrier comparison

For a carrier set, compute:

- shared declared invariants;
- per-carrier losses;
- per-carrier introductions;
- unresolved differences;
- agreement count;
- independence state.

Agreement never implies independence. Independence defaults to `NOT_ESTABLISHED` unless supplied by an explicit independence contract.

### 4. BBF-style analogy reconstruction

Analogical transport follows:

```text
FOLD(source)
→ MAP(source_structure → target_structure)
→ UNFOLD(target)
→ RECONSTRUCT(source invariants)
→ COMPARE
```

Outcomes:

- `PRESERVED`;
- `LOSS`;
- `INTRODUCED`;
- `UNRESOLVED`.

An analogy may generate a hypothesis or test design. It may not transfer evidence or truth authority from source domain to target domain.

### 5. Promotion gate

A multi-carrier candidate may receive one of:

```text
PRESERVE
PROMOTE_SUCCESSOR
REOPEN
REJECT
UNRESOLVED
```

`PROMOTE_SUCCESSOR` requires:

- declared source invariants preserved;
- no unresolved authority-transfer confound;
- bounded verification checks passed;
- candidate already admitted where fit/selection is involved;
- explicit claim ceiling retained.

Carrier agreement alone can never satisfy the gate.

## Deterministic bounded implementation

The reference implementation is standard-library Python and operates on explicit dictionaries/records. It is a calibration and orchestration layer, not a trained semantic model.

It must support:

1. deterministic role resolution from explicit role hints plus bounded lexical/context cues;
2. multiple active roles for one occurrence;
3. separate human/machine interpreter bindings;
4. four carrier records for one semantic object;
5. invariant/delta comparison across carriers;
6. BBF analogical round-trip checks;
7. cross-carrier confound audit;
8. gated disposition with explicit failure reasons;
9. deterministic JSON audit output.

## Known confounds and controls

### STATIC_ROLE_FALLACY
Treating a word as having one permanent system role.  
**Control:** role binding requires a context object and preserves multiple roles.

### INTERPRETER_COLLAPSE
Treating human and machine interpretations as identical.  
**Control:** bindings are keyed by interpreter and compared without forced merge.

### AGREEMENT_AS_TRUTH
Treating agreement among carriers as truth.  
**Control:** agreement is descriptive only; truth/evidence requires external declared authority.

### AGREEMENT_AS_INDEPENDENCE
Treating four transformed views from one source as four independent witnesses.  
**Control:** independence defaults to `NOT_ESTABLISHED`.

### ANALOGY_AS_EVIDENCE_TRANSFER
Treating a structural analogy as target-domain evidence.  
**Control:** analogical records have `authority_effect = NONE` and `evidence_transfer = false`.

### COMPUTATION_AS_GENERAL_PROOF
Promoting a finite computational witness to a universal theorem.  
**Control:** computational records carry domain/bound metadata and a claim ceiling.

### ANALYSIS_AS_EMPIRICAL_VALIDATION
Treating internal coherence as empirical validation.  
**Control:** analytical records distinguish derivation from observation.

### SYMBOLIC_COMPRESSION_AS_TRUTH
Treating a concise equation/label as more authoritative because it is compact.  
**Control:** symbolic carrier retains source/provenance and cannot promote itself.

### FIT_BEFORE_ADMISSION
Optimizing attractive surfaces before semantic admission.  
**Control:** existing GSFL admission-before-fit rule remains unchanged.

## Success criteria

A fresh exact-head verification must demonstrate:

- contextual bindings are deterministic;
- at least one fixture binds the same word to different roles under different contexts;
- at least one fixture binds one occurrence to multiple simultaneous roles;
- human and machine interpretations remain separate;
- all four carriers preserve declared source invariants in a positive fixture;
- injected carrier loss is detected;
- injected carrier introduction is detected;
- analogy round-trip preservation and failure are both detected;
- agreement does not establish independence;
- promotion gate rejects agreement-only candidates;
- promotion gate admits only a bounded verified successor with all declared controls satisfied;
- repeated audit execution is byte-identical.

## Boundaries

```text
CONTEXTUAL_ROLE_RESOLUTION != UNIVERSAL_SEMANTIC_PARSER
ROLE_SUPPORT_SCORE != TRUTH_PROBABILITY
MULTI_CARRIER != MULTIPLE_INDEPENDENT_WITNESSES
ANALOGY != EMPIRICAL_EVIDENCE
COMPUTATION != UNIVERSAL_PROOF
ANALYSIS != OBSERVATION
SYMBOL != SUBJECT
COHERENCE != VALIDATION
PROMOTION != SOURCE_REWRITE
```

# Decision Field MMORPG — World Without Waste

A no-build browser MMORPG-style research world where the environment mutates constantly and every interaction can become a bounded gameplay observation.

This is currently a client-side MMO prototype, not an internet-scale authoritative MMO server. Same-browser tabs can see each other through `BroadcastChannel`; NPC populations and world events simulate a larger shard.

## Fuzzball

There is a deliberately obscure code-hidden artifact named **Fuzzball**. It is not shown in the ordinary UI or item list. Explorers can discover it through a specific interaction pattern encoded in the client. Once found, it opens **Quantum Frontier** encounters based on genuine unresolved physics questions.

Fuzzball never claims to solve those problems. It presents: the open question, known boundary, candidate observation, counterexample pressure, and an explicit `UNRESOLVED` state. The point is to turn frontier physics into playable investigation while preserving uncertainty.

## Controls

WASD/arrows move, Space pulses, E interacts, Q phase-shifts, R shouts, 1/2/3 changes carrier lens. Optional motion and speech controls are permission-gated.

## Decision-field direction

The field is modeled as an action-sensitive partition of observations. Merge states only while the protected action remains equivalent. When a counterexample appears, split the field, add a discriminating observation, weaken the claim, or remain unresolved. Carriers may reduce planning/search cost without becoming semantic truth.

Local adaptation is visible, resettable, and limited to coarse gameplay parameters. It does not infer sensitive traits.

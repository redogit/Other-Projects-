# Blank Page Lab — begin without deciding everything

A small research instrument for exploring a blank page as a carrier, a view,
an arrangement, an expressive opportunity, or a place to begin. These are lenses,
not a universal definition of a page or a theory of nothingness.

The user asks to investigate how their blank-page exploration helped make
`OLU_Surface` and `OLU_Context`. This project preserves that recollection and makes
the missing historical links visible. It does not invent definitions for those names.

## What was recovered

A September 5, 2026 assistant-authored note titled *Orbit — The Blank Page* was
reviewed during this work. It treats the page as a bounded place to begin without
forcing a subject, vocabulary or answer; observations and interpretations remain
distinct; relevant prior pages may be brought forward without activating all history.
It explicitly labels the page/margin/stack arrangement as an optional metaphor,
not mandatory architecture, and corrects an earlier unsupported causal ladder
from change to experience and evolution.

That note is a contextual record, not a verbatim transcript of the user's original
insight. The original dated derivation of `OLU_Surface` and `OLU_Context` was not
recovered in the bounded search. The user's current recollection is preserved as
such; the causal chain remains unresolved. No complete private note, archive,
personal information or private access link is republished here.

## Try the instrument

Python 3.10+, standard library only. From the repository root:

```sh
python "Blank Page Lab/page.py" "Blank Page Lab/example.json"
python -m unittest discover -s "Blank Page Lab" -p 'test_*.py' -v
```

Copy the example locally. Keep exact marks, including whitespace and Unicode.
Record who or what is viewing the page, the question, carrier state, source references,
and the definitions actually supplied by the author. `null` means unresolved,
not empty, meaningless or absent. The tool prints questions for missing definitions
and historical links. It does not contact services or save your input elsewhere.
The input size cap is 1 MB; this is a local prototype, not a hardened untrusted-input service.

## A useful investigation

- Keep the same page and question; change only which source reference is available.
- Compare empty text with whitespace or visually hidden characters. An empty display
  is not a reliable test for missing bytes or missing context.
- Record observation, interpretation, intended use, and observed benefit separately.
- For your history, attach the earliest dated mark you can recover, later definitions,
  and intervening corrections. Keep your recollection beside the records.
- Ask what would distinguish a genuine historical influence from a useful connection
  noticed later. The instrument does not answer that from similarity alone.

These are proposed inquiries, not completed human-subject experiments. No benefit
to learning or accessibility is established by passing software tests. No collection
of other people's data, participant study or consent process is initiated.

## Evidence labels

`user_recollection`, `assistant_interpretation`, `documented_sequence`, and `unresolved`
remain distinct. A documented sequence requires reference strings, but the program
cannot authenticate those references, prove their dates or infer causation.
Missing references prompt recovery, not invention. The first original definition
should be preserved; a proposed new definition belongs in a separately dated successor.

The names `OLU_Surface` and `OLU_Context` are deliberately not equated with input boxes,
memory, the physical page, or the entire system. Such mappings need the user's source definitions.

## Boundaries and related work

The page may help organize a Hodge investigation, but organizing a claim does not
prove it. [Hodge Span Lab](../Hodge%20Span%20Lab/README.md) tests exact supplied
coordinates; this lab inspects the source/interpretation conditions around a task.
The person, recorded model, source, working set and assisting system remain distinct.

The public package is a new assistant-authored implementation, not a recovered OLU
engine or an authorized replacement for historical definitions. Its tests check
empty/whitespace distinctions, mutation avoidance, unknown definitions and rejected
unsupported evidence labels. Human usability and screen-reader testing remain open.

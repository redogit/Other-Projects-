# S'1 Rigor Layer and Carrier/Ops v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an independent quantified rigor layer, collision fail-closed handling, and a recursively closed S'1 Carrier/Ops v1 without changing v0 semantics.

**Architecture:** Keep production v0 transforms and operators intact. Add a sidecar matrix/conditioning verifier, make replay hashing collision-aware by pairing digests with canonical descriptors, then add a separately versioned immutable carrier AST whose operators are closed over their own outputs. Extend audit/CI and freeze a successor evidence artifact only after exact-head verification.

**Tech Stack:** Node.js >=22, dependency-free ECMAScript modules, node:test, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-18-s1-rigor-v1-design.md`

## Global Constraints

- Preserve every existing v0 serialized schema and operator meaning.
- No external runtime dependencies.
- `SOFTWARE_VERIFICATION != SCIENTIFIC_VALIDATION`.
- `FINITE_EXHAUSTIVE_SWEEP != UNBOUNDED_PROOF`.
- `HASH_EQUALITY != PAYLOAD_EQUALITY`.
- Existing Experiment 0 evidence remains immutable.
- Exact PR-head SHA must be what CI verifies.
- Every production-code behavior starts with a failing test.

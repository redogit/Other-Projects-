# Operator Skills — Coordination Layer

This file coordinates the operator Skill/Agent suite with the surrounding research/work system without merging project authority.

## Separation rule

Projects remain separate objects. Cross-links may **inform, pressure, test, locate, or propose**. They do not automatically transfer evidence, authority, identity, applicability, PASS/FAIL state, or admission.

The method artifacts here are reusable. Project conclusions remain with their owning project.

## Handoff packet

Every cross-project handoff should carry:

```yaml
handoff_id: <stable id>
from_project: <owner>
to_project: <receiver>
source_revision: <commit/hash/version>
subject: <subject>
motivator: <why now>
request: <bounded request>
obligation: <must remain true>
surface: <active boundary>
output_definition: <completion condition>
evidence_refs: <exact refs>
authority_scope: <what can change>
claim_ceiling: <strongest permitted claim>
status_vector: <tested/negative/unresolved/verified/etc>
unknowns: <explicit remainder>
return_route: <owning project / agent>
```

A receiving Agent must not reinterpret missing fields as permission.

## Agent society

Use the smallest effective set of roles.

- **Root orchestrator/integrator:** decomposes and routes; cannot supply missing verification or ratification authority.
- **Operator Agents:** execute one durable skill each.
- **Role-separated reviewers:** apply different pressure roles; call them independent only under an explicit validated independence contract.
- **Integrity/sentinel review:** checks provenance, leakage, contamination, authority expansion, and schema fidelity where consequential.
- **Economic review:** compares full lifecycle cost when selection depends on cost.
- **Ratifier/archive:** only the authorized owner may commit categorical canonical state.

## Shared evidence discipline

Always preserve:
- executed/verified results;
- negative results;
- learned distinctions;
- interpretation errors;
- boundary changes;
- unresolved questions;
- source provenance and exact revision where available.

Coherence and agreement are not proof. Repeated sources are not automatically independent. External evidence must remain distinguishable from internal project evidence.

## Two-pass integration

For substantial updates:
1. first pass: route, integrate, and preserve distinctions;
2. second pass: re-check omissions, provenance, authority leakage, contradictory evidence, and unsupported promotion.

Only then prepare the final handoff or PR summary.

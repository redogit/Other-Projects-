# Fuzzball

Fuzzball is a deliberately code-hidden artifact in the Decision Field MMORPG.

It unlocks a **Quantum Frontier** encounter system containing real open questions in quantum foundations, quantum gravity, black-hole information, dark matter and cosmology.

The artifact follows four rules:

1. An open problem remains `UNRESOLVED` unless the game has a bounded, explicit result.
2. A finite computation is not promoted into a universal theorem.
3. A representation, carrier or analogy is not treated as physical truth.
4. A counterexample is progress: it changes the playable hypothesis space.

The name is playful and is not a claim that the game implements or validates any particular fuzzball proposal in string theory.

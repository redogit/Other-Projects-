# GSFL integration and authority map

GSFL is cross-cutting, but cross-cutting does not mean authority-transferring.

## Operative implementation home

The public reference implementation belongs in:

```text
redogit/Other-Projects-/Generalized Semantic Fitting Language/
```

This follows the current project-routing rule that `Other-Projects-` is the user's implementation destination while earlier or companion Conscience64 material remains cross-reference/recovery context.

## Conscience64

Conscience64 should carry a **research-navigation / provenance cross-reference** to GSFL, not a second implementation.

Permitted relation:

```text
CONSCIENCE64 --references--> GSFL
```

Not permitted merely by reference:

```text
CONSCIENCE64_REFERENCE == GSFL_VERIFICATION
CONSCIENCE64_RETRIEVAL == INDEPENDENT_EVIDENCE
```

## TBCL / Context Language Lab

GSFL is structurally related to TBCL because both deal with semantic transport, context, and reconstruction. TBCL remains authoritative for its own language/runtime contracts.

```text
GSFL_RELATED_TO_TBCL != GSFL_MERGED_INTO_TBCL
```

Potential bridge work may compile selected GSFL declarations into TBCL or vice versa, but that is future integration work and must preserve each language's source semantics and provenance.

## CSOL

GSFL operationalizes a compatible human-use quality direction: preserve meaning while reducing cognitive effort and ambiguity. CSOL remains its own language-quality framework.

```text
GSFL_FIT_SCORE != CSOL_UNIVERSAL_SCORE
```

The v0 score is a bounded engineering surrogate and must not overwrite CSOL definitions.

## Decision Field Operator Lab

GSFL's `ROTATE`, `FIT`, `COMPARE`, `REPAIR`, `VERIFY`, and `RECONSTRUCT` vocabulary can consume or describe operator candidates from the Decision Field Operator Lab.

The operator lab remains authoritative for its finite operator-space evidence. GSFL does not convert operator registration or fit into universal optimality.

```text
OPERATOR_REGISTERED != SEMANTICALLY_ADMITTED
FIT_SELECTED != UNIVERSALLY_OPTIMAL
```

## N-observer accessibility work

The first executable GSFL example is the N-observer accessibility field developed from the Windows multi-magnifier discussion.

GSFL does not implement Windows magnification itself. It tests the semantic transformation from the technical N-observer model to candidate human surfaces while preserving:

- N-cardinality;
- unchanged observed world/desktop state;
- independent observation geometry;
- independent presentation geometry.

This provides a concrete usefulness witness for GSFL without conflating language verification with accessibility-device validation.

## Orbit / Library

Orbit may index GSFL and its relations. Source custody remains with the GSFL project and retained Library packet.

```text
INDEXED != INGESTED_AS_AUTHORITY
RELATED != SUPPORTS
```

## Operator Moonshot / R³

GSFL can be used as a representation/fitting layer in bounded experiments. R³ and Operator Moonshot continue to govern their own scientific admission and evidence rules.

GSFL fit is never a scientific promotion step.

## Private Library
